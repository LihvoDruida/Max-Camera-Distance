# Max Camera Distance v11.3.0

## Встановлення

Скопіюйте папку `Max_Camera_Distance` в `Interface/AddOns` вашого клієнта WoW.
Папка повинна містити `Max_Camera_Distance.toc`, `manifest.xml`, Lua-файли та `libs`.
Замініть стару папку адона. Не видаляйте `WTF`: наявні профілі зберігаються.
**Важливо:** релізний ZIP, зібраний BigWigsMods Packager, містить усі сторонні
бібліотеки. **Source ZIP** містить лише репозиторій, у якому п'ять зовнішніх
бібліотек завантажуються під час релізного пакування. Не встановлюйте Source ZIP
як повноцінний аддон. Архів Overlay 11.3.0 призначений для накладення на вже
встановлений комплектний Max Camera Distance; він не замінює відсутні бібліотеки.

## Налаштування

Налаштування доступні в меню гри: **Налаштування → Аддони → Max Camera Distance**.
Там відкривається повний власний інтерфейс у компактному компонуванні, з поясненнями
під списком параметрів. Категорія підтримує сучасний Settings API та InterfaceOptions.

Початкова вкладка **Огляд** показує лише найуживаніші параметри: ручну
дистанцію, прискорення зуму, бойовий зум, маунтів, AFK та мову/кнопку мінікарти.
Оберіть іншу категорію для розширених параметрів. Над списком пошуку тепер є
кількість знайдених пунктів; кнопка X очищає запит. Підсвічування вкладки й
наведеного елемента допомагає побачити, що зараз редагується.

Відкрийте окреме вікно командою `/mcd config`, кнопкою мінікарти або призначеною клавішею.
Темне вікно із золотими акцентами, бічні розділи, глобальний пошук, панель пояснень,
прокрутка, числове введення біля повзунків, індикатор клієнта та дистанції камери.
Esc закриває вікно. Розмір автоматично пристосовується до доступного екрана.
Зміни застосовуються одразу; вибір мови, як і раніше, перезавантажує UI.

Залишено ручну дистанцію, пресети, Smart Zoom для бою й різних активностей,
налаштування маунтів і форм, Reactive Zoom, ActionCam і компенсацію плечового зсуву,
AFK-режим, додаткові можливості, діагностику та налаштування Forever.
Недоступні можливості приховуються відповідно до клієнта та його API/CVar.
Геймпад, туман і додаткові ефекти оточення Forever зберігають свою окрему область застосування.

У розділі профілів можна вибрати, створити, скопіювати, видалити або скинути профіль.
Копіювання, видалення і скидання вимагають підтвердження у вікні адона.

## Команди

- `/mcd config` — власне вікно налаштувань.
- `/mcd status` — діагностика стану камери та CVar.
- `/mcd deps` — комплектність бібліотек і готовність налаштувань.
- `/mcd shoulder toggle|swap|center|config` — керування плечовою камерою.
- `/mcd autozoom`, `/mcd automount` — перемикання автоматичних режимів.
- `/mcd gamepad` — діагностика геймпада Forever.
- `/mcd help` — довідка.

## Перевірки вихідного коду

Потрібні Python 3 і Lua 5.1 (`lua5.1`, `luac5.1`). Запуск: `bash check_all.sh`.
Тести та інструменти не завантажуються грою і не додають навантаження під час гри.

Для GitHub завантажуйте весь вихідний комплект, включно з `libs/`,
`libs/_manifest.xml` і `.github/workflows/package.yml`. Приватна бібліотека `LibCamera` зберігається
у репозиторії; п'ять залежностей завантажуються BigWigsMods Packager під час
релізного пакування, після чого перевіряються маніфест і ZIP.
Перед публікацією окремо перевіряються зібрана папка й фактичний ZIP.

## Групування v11.1.0

Розділи: Огляд; ручна камера; перехід і колесо зуму; бій та активності;
маунти/форми; ActionCam (або геймпад Forever); AFK; колізії/візуальні параметри;
графіка Forever; додаткові дії; діагностика; профілі. Недоступні спеціальні сторінки
приховуються. Для кожної бойової активності пресет, ручна дистанція й затримка
повернення стоять разом. Профілі використовують ті самі ключі збереження.

Наявність налаштувань CVar та режиму літальних маунтів визначається за API клієнта.
Mythic+ залишається Retail-only; сценарії доступні в Retail і Mists; Arena та
режим літальних маунтів відсутні в Classic Era. Titan Reforged позначається окремо.
Підтримка описує сучасні сімейства клієнтів; точний набір API приватних форків
потребує перевірки в грі.


## CI / зовнішні бібліотеки

П'ять сторонніх бібліотек (`LibStub`, `CallbackHandler-1.0`, `AceDB-3.0`,
`LibDataBroker-1.1`, `LibDBIcon-1.0`) **не зберігаються у вихідному коді**:
їх отримує BigWigs packager за `.pkgmeta` під час формування релізного ZIP.
Власна `LibCamera` залишається в `libs/LibCamera/`.

```bash
python3 tools/verify_manifest.py --allow-missing-externals  # source checkout
bash check_all.sh                                              # source checks
# Після пакування -- жорстко перевіряється вся папка libs/:
python3 tools/verify_manifest.py --root .release/Max_Camera_Distance
MCD_PACKAGED_ROOT="$PWD/.release/Max_Camera_Distance" bash check_all.sh
```
